- Usar componentes `<flux:*>` en Blade/Livewire.
- Theming, dark mode, layouts y personalización.

## Cómo actualizar

Desde la raíz del exportador:

```bash

```

Los `.mdc` se escriben en `.cursor/skills/flux/`.
