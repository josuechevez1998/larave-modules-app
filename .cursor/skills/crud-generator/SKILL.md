# Ibex CRUD Generator

## Purpose
Scaffold standard CRUDs only. Special features are hand-written Services + Livewire.

## Install
```bash
composer require ibex/crud-generator --dev
php artisan vendor:publish --tag=crud
php artisan vendor:publish --tag=stubs-crud
```

## Usage

```bash
# App root (default)
./vendor/bin/sail artisan make:crud {table} livewire
./vendor/bin/sail artisan make:crud {table} api

# Into a nwidart module
./vendor/bin/sail artisan make:crud {table} livewire --module=Blog
./vendor/bin/sail artisan make:crud {table} api --module=Blog
```

The project command `App\Console\Commands\MakeCrudCommand` extends ibex and adds `--module=`.

## Custom stubs
Published under `resources/stubs/crud/`. Adapted for:
- `{Model}Service` (also generated by MakeCrudCommand)
- Livewire Flux + `ui-*` (light/dark); includes vía `{{modelViewFull}}`
- Index filters per column (text / catalog select) + `<x-ui.clear-filters />` + `ListQueryBuilder::withColumnFilters()`
- Form FK columns → catalog `flux:select` + `{relation}Options()`
- Diglactic breadcrumbs (`routes/breadcrumbs.php`) + SweetAlert toast (`flash_swal_toast` / confirm delete)
- Thin API controllers
- Module paths/namespaces when `--module=` is set
