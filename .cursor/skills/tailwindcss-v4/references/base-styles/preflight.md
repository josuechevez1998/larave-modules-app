# Preflight

Preflight aplica una base consistente sobre estilos predeterminados del navegador.

## Reglas

- Importar Tailwind incluye Preflight.
- Los márgenes predeterminados se eliminan y el box-sizing se normaliza.
- Imágenes, SVG y otros medios reciben comportamientos base consistentes.
- Añade correcciones del proyecto en la capa base, sin editar archivos de Tailwind.
