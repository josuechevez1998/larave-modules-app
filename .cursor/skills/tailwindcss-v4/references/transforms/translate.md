# translate

Controla transformaciones 2D/3D y perspectiva.

## Uso en el proyecto

- Consulta esta referencia cuando necesites trabajar con **translate**.
- Aplica variantes como `hover:`, `focus:`, `dark:` y breakpoints cuando el diseño lo requiera.
- Usa valores del tema antes de recurrir a valores arbitrarios.
- Un valor arbitrario debe escribirse como una clase completa y estática para que Tailwind pueda detectarlo.
- Evita construir nombres de clases mediante concatenación de fragmentos.

## Clases frecuentes

```html
<div class="translate-x-4 -translate-y-1/2"></div>
```

## Valores arbitrarios

Cuando la escala no cubra el caso, utiliza la sintaxis arbitraria documentada para `translate`, por ejemplo una clase completa con `[...]`.
