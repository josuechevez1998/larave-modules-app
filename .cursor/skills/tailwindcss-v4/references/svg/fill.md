# fill

Controla relleno y trazo de SVG.

## Uso en el proyecto

- Consulta esta referencia cuando necesites trabajar con **fill**.
- Aplica variantes como `hover:`, `focus:`, `dark:` y breakpoints cuando el diseño lo requiera.
- Usa valores del tema antes de recurrir a valores arbitrarios.
- Un valor arbitrario debe escribirse como una clase completa y estática para que Tailwind pueda detectarlo.
- Evita construir nombres de clases mediante concatenación de fragmentos.

## Clases frecuentes

```html
<div class="fill-current fill-sky-500 fill-none"></div>
```

## Valores arbitrarios

Cuando la escala no cubra el caso, utiliza la sintaxis arbitraria documentada para `fill`, por ejemplo una clase completa con `[...]`.
