# Upgrade guide

Guía para migrar proyectos anteriores a Tailwind CSS v4.

## Reglas

- Ejecuta la herramienta oficial de actualización cuando el proyecto venga de v3.
- Revisa cambios de configuración JavaScript a configuración CSS-first.
- Sustituye `@tailwind base/components/utilities` por `@import "tailwindcss";`.
- Valida plugins, clases renombradas, valores por defecto y comportamiento de bordes/sombras.
