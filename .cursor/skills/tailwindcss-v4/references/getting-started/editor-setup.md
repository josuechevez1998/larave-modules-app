# Editor setup

Configura IntelliSense, reconocimiento de sintaxis Tailwind y formateo de clases.

## Reglas

- Instala la extensión oficial Tailwind CSS IntelliSense en editores compatibles.
- Asocia archivos CSS con sintaxis Tailwind cuando el editor marque `@theme`, `@utility` o `@variant` como desconocidos.
- No desactives validaciones CSS globalmente si basta con configurar el lenguaje del archivo.
