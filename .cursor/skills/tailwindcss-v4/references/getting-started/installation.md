# Installation

Selecciona el método de integración adecuado. Para aplicaciones Laravel que ya usan Vite, el plugin `@tailwindcss/vite` es el flujo principal.

## Reglas

- No mezclar instrucciones de Tailwind v3 con Tailwind v4.
- En v4, importa Tailwind con `@import "tailwindcss";`.
- Usa el plugin de Vite cuando el proyecto ya compila recursos con Vite.
- Mantén una única hoja CSS principal para tema, fuentes y extensiones globales.
