# Adding custom styles

Extiende Tailwind con CSS normal, componentes, utilidades personalizadas y variantes.

## Reglas

- Usa CSS normal para estilos globales que no deban ser utilidades.
- Registra utilidades reutilizables mediante `@utility`.
- Registra variantes del proyecto mediante `@custom-variant`.
- Usa las capas base, components y utilities cuando necesites controlar precedencia.
- Prefiere tokens del tema antes que valores repetidos.
