# Responsive design

Tailwind aplica un enfoque mobile-first mediante variantes de breakpoint.

## Reglas

- Las clases sin prefijo son la base móvil.
- Usa `sm:`, `md:`, `lg:`, `xl:` y `2xl:` para cambios desde ese ancho en adelante.
- No uses `sm:` como sinónimo de teléfono; representa el breakpoint mínimo `sm`.
- Usa variantes `max-*` para rangos limitados y container queries cuando el componente dependa de su contenedor.
