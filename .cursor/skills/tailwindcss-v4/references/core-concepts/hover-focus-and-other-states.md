# Hover, focus, and other states

Aplica variantes condicionales para estados, estructura, atributos, medios y relaciones.

## Reglas

- Usa prefijos como `hover:`, `focus:`, `disabled:`, `first:`, `odd:` y `aria-*:`.
- Combina variantes de izquierda a derecha, por ejemplo `dark:md:hover:bg-sky-700`.
- Usa `group-*` para reaccionar al estado de un ancestro y `peer-*` para un hermano anterior.
- Usa variantes arbitrarias solo cuando no exista una variante semántica reutilizable.
