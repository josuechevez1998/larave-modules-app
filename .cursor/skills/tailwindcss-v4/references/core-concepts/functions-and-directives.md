# Functions and directives

Referencia de directivas y funciones CSS proporcionadas por Tailwind v4.

## Reglas

- `@import "tailwindcss"` carga el framework.
- `@theme` define tokens; `@source` controla fuentes; `@utility` crea utilidades.
- `@variant` aplica una variante dentro de CSS y `@custom-variant` registra una nueva.
- `@apply` incrusta utilidades existentes; úsalo con moderación.
- `@reference` comparte tema/utilidades sin emitir CSS duplicado.
- `@config` y `@plugin` existen para compatibilidad con configuraciones y plugins heredados.
