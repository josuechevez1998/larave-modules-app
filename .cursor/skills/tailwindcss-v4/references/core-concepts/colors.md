# Colors

Usa la paleta integrada o define colores semánticos mediante variables de tema.

## Reglas

- Usa opacidad con sintaxis como `bg-sky-500/50`.
- Usa `currentColor`, `transparent`, `black` y `white` cuando corresponda.
- Para una marca, crea nombres semánticos como `--color-primary` y `--color-surface`.
- Comprueba contraste y estados de foco; el color no debe ser la única señal.
