# Styling with utility classes

Construye interfaces combinando utilidades pequeñas directamente en el marcado.

## Reglas

- Compón clases de responsabilidad única en Blade, HTML, JSX o componentes.
- Extrae componentes cuando el patrón visual y su comportamiento se repitan.
- Usa valores arbitrarios solo para valores realmente excepcionales.
- Usa propiedades arbitrarias para CSS que no tenga una utilidad nativa.
- No reemplaces todas las utilidades por `@apply`; conserva el flujo utility-first.
