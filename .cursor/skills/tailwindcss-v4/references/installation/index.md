# Instalación de Tailwind CSS v4.3

Selecciona un método de instalación según el pipeline del proyecto.

- **Vite:** recomendado para este proyecto Laravel/Vite.
- **PostCSS:** para pipelines que ya dependen directamente de PostCSS.
- **CLI:** para proyectos simples o compilación independiente.
- **Framework Guides:** instrucciones específicas por framework.
- **Play CDN:** solo para pruebas y prototipos, nunca producción.

Fuente oficial: https://tailwindcss.com/docs/installation
