# Guías por framework

La documentación oficial ofrece integraciones específicas para frameworks como Laravel, Next.js, Nuxt, SvelteKit y otros.

Para este proyecto:

1. Mantén Laravel Vite Plugin.
2. Añade `@tailwindcss/vite`.
3. Importa Tailwind desde la hoja CSS principal.
4. Incluye las entradas CSS/JS mediante `@vite(...)`.
5. Mantén clases completas en Blade y componentes Livewire.

Fuente oficial: https://tailwindcss.com/docs/installation/framework-guides
