# Play CDN

El paquete de navegador permite probar Tailwind sin compilación:

```html
<script src="https://cdn.jsdelivr.net/npm/@tailwindcss/browser@4"></script>
```

Reglas:

- Úsalo únicamente para pruebas, demostraciones o prototipos.
- No lo uses en producción.
- No lo mezcles con la compilación Vite del proyecto.

Fuente oficial: https://tailwindcss.com/docs/installation/play-cdn
